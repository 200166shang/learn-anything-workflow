# Learn Anything

把用户的自然语言意图编排成持久学习流程。用户只负责说明想学什么、材料在哪里，以及在关键选择点做决定；底层命令、对象 ID 和文件布局由你管理。

固定学习库为 `/Users/syz/VideoLearning/workspace.toml`。从任何代码目录或新会话调用本 Skill 时都使用这个配置；用户给出的其他目录是学习材料，不是新的学习库。

## 进入流程

1. 判断用户要开始、继续、复习、练习，还是查看成果。读取对应分支所需的兄弟 Skill 全文后再行动。
2. 先查询持久状态。新会话不等于新模块；能够恢复已有模块、线程或问题时，向用户呈现恢复结果。
3. 只询问当前动作缺少的信息。开始新学习时至少确认材料和本次范围；存在多个可恢复目标时给出少量明确选项。
4. 通过公开 `video-extract` CLI 持久化事实。把内部命令、ID 查找、重试和路径解析留在 Agent 内部。
5. 每轮结束说明已保存什么、当前问题是什么，以及用户接下来可以“继续、返回、暂放、复习或练习”中的哪些动作。

完成标准：用户的实际选择已经持久化，或系统明确停在一个需要用户选择/补充材料的边界；一次临时源码摘要不算完成。

## 开始新的学习

读取 `../learning/SKILL.md`。根据材料类型按需读取：

- 视频、音频、字幕或 URL：`../extract-media/SKILL.md`，材料准备好后读取 `../source-notes/SKILL.md`。
- 已下载媒体、转写或文档：登记并复用现有产物；需要来源笔记时读取 `../source-notes/SKILL.md`。
- 源码目录：登记固定源码版本，先建立模块边界和根问题。可以使用源码理解工具勘察调用链，但其输出只是教学证据，必须回到 `learning` 保存问题、讲解和反馈。

确认本次范围后才创建新模块。让 `learning` 推荐少量能串起范围的根问题，解释关系并等待用户选择；推荐项在被选择前不进入历史。用户选定后立即保存根问题，再生成有来源区分、因果链和边界条件的讲解。

## 继续学习或追问

读取 `../learning/SKILL.md`，先执行只读恢复。展示当前模块、当前问题、理解反馈、未解困惑和返回路线。停在暂放问题时，让用户选择继续该问题或返回，不替用户决定。

用户实际提出的每个追问先保存，再讲解。AI 可以说明候选子问题与当前主线的关系，但只有用户选择的分支进入历史。已有问题被再次进入时保留原身份，并记录本次入口和用户的实际问法。

讲解后用自然语言询问最有价值的状态选择：已经理解、仍不理解、回答检查，或暂放。只保存用户明确表达的反馈。

## 复习、闪记与练习

- 用户说“复习、回忆、抽查、今天学什么”时读取 `../review/SKILL.md`。先给少量建议，用户选定后才开始主动回忆；答案在用户尝试前保持隐藏。
- 用户明确要记忆某个结论时，按 `review` 的卡片生命周期先提议再选择；未选卡片不保存。
- 用户说“练习、带我写、手写一个”时读取 `../practice/SKILL.md`。练习绑定已有问题和讲解，范围保持为一个约 10–25 分钟可运行的小机制，用户先写，Agent 逐级给提示。
- 用户要制作中文听力材料时读取 `../mandarin-audio/SKILL.md`；上传或发布是独立且需明确授权的动作。

复习和练习保存各自事实，不自动改变 Learn 的当前位置或理解反馈。

- 旧 Obsidian 库：`/Users/syz/VideoLearning/学习系统`

优先通过公开查询定位当前模块、问题和正式讲解；对象存储文件不是让用户手工编辑的笔记。若 Obsidian 尚未投影最新内容，明确说明“事实已保存、可读投影待生成”，并重建派生视图；保留旧笔记作为只读历史。

## 用户说法

用户可以只说：

- `$learn-anything 我想学习小沫机器人语音模块，源码在 /Users/syz/code/robot`
- `$learn-anything 继续上次的小沫机器人学习`
- `$learn-anything 今天复习什么？`
- `$learn-anything 把当前问题做成一个小练习`
- `$learn-anything 我想看看已经保存的学习文档`

把这些话转换成流程，不要求用户补写 CLI 命令或记住内部 Skill 名称。
