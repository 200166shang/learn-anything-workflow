# 学习地图视图原型（一次性决策参照）

打开 index.html，在局部问题图与模块全景图间切换。使用虚构数据，点击仅预览，不保存学习状态。fragment.html 是会话内展示源文件。

用户确认：日常续学用局部图，回顾模块用全景图，保留目录用于快速查找；正式生成与持续维护的地图应保持本示例的呈现效果。

视觉与行为基准：顶部续学位置及本次返回路线；问题卡片中的名称、独立理解反馈和内容可用状态；当前位置突出；实线实际追问、虚线跨根引用；局部聚焦与模块根问题分组；点击查看不改续学位置；窄屏仍可辨认。目录是补充入口，不能替代两种图。

此原型并未实现真实 Obsidian 导航、完整讲解、数据生成、冲突协调或持久化。正式版须接入真实讲解定位，而不能把示例短预览当成完整学习体验；技术载体和视觉回归检查由后续规格与实现明确。界面随内容量适配，不要求坐标和像素逐一固定。
